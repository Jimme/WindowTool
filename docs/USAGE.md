# 使用说明

当前正式版：**0.1.3**。历史版本行为见[更新记录](../CHANGELOG.md)。

## 界面与入口

WindowTool 使用同一个窗口，标签顺序为 **窗口 → 常规 → 快捷键 → 状态与诊断 → 关于**。

- 托盘双击、托盘“窗口管理…”、Win+F9 或再次启动同一路径的程序，打开已有实例的“窗口”页。
- 托盘“设置…”打开“常规”页。
- “窗口”页显示已收起的窗口、所属程序和收起时间；双击一行或选择后点击“恢复选中”即可恢复。
- 恢复操作立即生效。空列表禁用恢复按钮，未选中行时禁用“恢复选中”。底部显示数量及提醒，详细原因见“状态与诊断”。
- “常规”和“快捷键”页提供确定、取消、应用、恢复当前页默认；其他页提供关闭。切换标签保留未应用修改。

## 快捷键

在 **设置 → 快捷键** 中单独录制、启用或停用十项操作。下表与界面顺序一致，适用于新安装；已有配置不会自动替换。

| 功能 | 默认快捷键 |
| --- | --- |
| 收起当前窗口 | Ctrl+Shift+CapsLock |
| 恢复最近窗口 | Ctrl+Alt+CapsLock |
| 打开管理界面 | Win+F9 |
| 窗口左 / 中 / 右 | Win+F10 |
| 窗口上 / 中 / 下 | Win+F11 |
| 窗口居中 | Win+F12 |
| 恢复全部窗口 | 未启用，可自行设置 |
| 打开设置 | 未启用，可自行设置 |
| 修复托盘图标 | 未启用，可自行设置 |
| 退出并恢复窗口 | 未启用，可自行设置 |

点击“录制…”再按组合键，支持 Tab、CapsLock、Win 和普通按键。Esc 取消；15 秒超时、切换标签或离开窗口也会取消录制。录制期间暂时停止本程序的键盘钩子，结束后等待松开按键再恢复。

修改后点击“应用”生效；“确定”应用后关闭，“取消”放弃未应用修改。关闭窗口或主动退出时，如有未保存修改会询问保存、放弃或取消；保存失败保留窗口并显示原因。系统关机、注销不弹出保存询问。“恢复当前页默认”只重置本页待应用选项，需再点击应用。

状态栏区分待录制、待启用、待停用、待修改和实际运行状态。应用时检查重复组合、取得新注册并写入配置；失败保留旧注册与配置。临时冲突的已保存键位不会因为保存其他设置而被清空；释放占用后，在“状态与诊断”点击“重新检测快捷键”。

### 冲突与限制

- 六个默认组合在本程序内部互不重复，但系统和其他软件可能占用。
- **Win+F11 可能与 Windows 11 的 Xbox 模式冲突。** 关闭 Xbox 模式入口不保证立即释放快捷键；仍不可用时可自定义其他组合。见[微软说明](https://support.microsoft.com/en-us/servicing/os/windows/docs/2025/10/windows-gaming-full-screen-experience)。
- Ctrl+Shift+CapsLock / Ctrl+Alt+CapsLock 避开浏览器常用的 Ctrl+Shift+Tab，但讲述人等辅助功能可能把 CapsLock 作为修饰键。
- F12 被系统注册接口列为调试器保留键，因此 Win+F12 使用键盘钩子；CapsLock 同样使用钩子，以抑制大小写切换。见[RegisterHotKey 文档](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。
- 钩子不能完整检测其他软件钩子的冲突；其他组合通过系统注册获取冲突反馈。应用内部快捷键不一定向系统注册，不能保证自动检测。

## 窗口定位

定位使用窗口当前所在显示器的工作区，避开任务栏。左右循环保持纵向位置，上下循环保持横向位置；居中调整两轴。桌面、任务栏及已最大化或最小化的窗口不处理。

定位明确保持窗口尺寸。DPI 不感知和系统 DPI 感知窗口的外框留在工作区内，避免不可见边框越过不同缩放屏幕的交界而触发坐标重缩放；可见内容与左、上边缘之间可能有数像素间隙。逐显示器 DPI 感知窗口继续按可见边框对齐。

定位先进行 50ms 响应检查，已无响应目标会跳过本次请求；正常请求异步提交，最多等待 60ms 确认。若目标在提交后才卡住，已提交请求仍可能稍后执行。实际耗时受 Windows 调度影响，这两个数值不是所有环境下的严格总耗时上限。

## 收起、恢复与托盘

收起的是当前窗口，不是整个程序的所有窗口。目标进程继续运行；普通窗口隐藏后不出现在 Alt+Tab 和任务栏窗口按钮中。程序自行创建或重新显示的其他窗口需要分别处理。桌面、任务栏、本程序自身及子控件不作为收起目标。

恢复最近或选中窗口会尝试激活目标；恢复全部和正常退出恢复只显示窗口，不主动抢焦点。最大化状态会保留。已关闭或自行重新显示的窗口自动清理。列表增量更新，保留选中项、滚动位置及手动列宽；改变程序列或时间列显示时重新分配列宽。

恢复使用异步请求。单个目标 3 秒未响应时保留窗口和磁盘记录，可继续恢复其他窗口，稍后重试。正常退出先有界等待 500ms；仍有窗口未恢复则取消普通退出。收起时间只记录本次运行，上次运行遗留记录显示“上次运行”。

托盘图标缺失时会重建。启动或收到任务栏重建通知后每 2 秒重试，成功即停止，最多 15 次；常驻每 30 秒检查一次。已有图标不重复删除重建。Windows 仍可能把图标放入折叠区。

托盘不可见时，可按 Win+F9 或再次启动同一路径的 EXE。二次启动只唤起已有实例，不替换它、不丢弃已收起窗口。管理员实例仅放行任务栏重建和打开管理界面的两种特定无参数通知。

## 配置与恢复记录

程序目录应允许当前用户写入。

| 文件 | 用途 |
| --- | --- |
| WindowTool.ini | 自定义快捷键及窗口列表显示选项 |
| WindowTool.hidden | 隐藏前写入的窗口恢复记录 |
| WindowTool.log | 启动、错误与托盘恢复日志，超过 512 KiB 轮换 |

恢复记录完整写入、刷新并替换成功后才隐藏窗口。异常退出后，以同一用户和足够权限从原目录启动，会尝试按记录恢复。窗口属性令牌用于防止句柄重用后误恢复其他窗口。

记录读取失败或格式损坏时保留原文件并禁止继续收起，避免覆盖待处理记录。仍有隐藏窗口或异常退出后，不要删除、移动恢复记录文件。

## 管理员自启动

从长期安装目录运行 EXE，打开 **常规 → 登录启动**，勾选“登录时以管理员身份启动”并点击应用。普通权限下会请求 UAC 授权，需使用当前用户的管理员权限，不支持改用其他账户。源码和预览模式只查看状态，不能修改正式自启。

“立即启用并修复自启”会立即启用并更新为当前路径，取消按钮不会撤销；“重新检测”更新实际状态并保留未应用的勾选。路径、运行结果及详细检查信息见“状态与诊断”。

程序创建当前用户专属的登录计划任务，以最高权限在交互桌面延迟 10 秒启动。不保存密码，不限制运行时长，使用电池也可运行；不主动唤醒电脑。实际启动时机受 Windows 调度和安装磁盘可用性影响。

任务记录当前 EXE 的绝对路径和工作目录。更新时保持安装路径不变；移动后从新位置修复自启。关闭勾选并应用只删除带本程序标记的专属任务，不终止运行中的实例。

启用成功后，仅将当前用户启动文件夹中指向同一 EXE、没有参数的快捷方式改名为 `.lnk.WindowTool-disabled` 备份。关闭自启不会恢复旧快捷方式。其他路径、带参数的快捷方式、注册表和第三方自启项不会自动修改。

安全软件可能拦截计划任务操作；请核对具体提示后自行审核，不建议整体信任 PowerShell 或关闭防护。

## 更新与版本

“关于 → 检查更新”手动查询 GitHub 最新正式版，有新版时提供发布页入口。不检查先行版，不自动下载或安装；网络失败或限流会显示提示，可稍后重试。

正式版如 `0.1.3`；测试版如 `0.1.3-alpha.1`、`0.1.3-alpha.2`；候选版可用 `0.1.3-rc.1`。完整版本显示在关于、诊断和 EXE 产品版本中，窗口标题与托盘提示保持 WindowTool。

升级已有安装：

1. 从旧版托盘正常退出，确认收起窗口已经恢复，并处理未保存设置。
2. 备份旧 EXE，解压新版本到原目录，保留 INI、恢复记录及日志。
3. 重新启动；操作管理员窗口时以管理员身份运行。
4. 若改变安装路径，从新位置修复自启，检查是否还有其他旧自启入口。

异常退出后应先恢复隐藏窗口，再移动目录或清理记录。不要同时运行两个正式实例。

## 验证范围

0.1.3 源码及编译版各通过 131 项检查，覆盖设置保存与失败处理、快捷键、定位、隐藏恢复、恢复记录、托盘通知和二次启动。定位包含三种 DPI 感知模式、150% 与 100% 双屏、快速连续调用、无响应及目标中途关闭。AudioBox 连续水平、垂直各 30 次实测无漂移及尺寸变化。

独立集成测试验证过计划任务注册、提权运行、迁移和失败回滚；0.1.1 曾获实机登录自启确认，不能替代 0.1.3 的真实登录验证。模拟任务栏重建通知也不等于真实 Explorer 崩溃重启。

其他特殊程序、屏幕排列、缩放组合、普通权限唤起管理员实例及长期运行仍需实机观察。报告问题时请说明完整版本和复现操作，提交日志或截图前去除私人窗口标题及路径。
